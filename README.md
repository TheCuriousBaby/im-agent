# IM Agent

本地运行的 IM 窗口自动化助手。它截取你选定的聊天窗口，交给你配置的视觉模型识别界面和消息，由回复模型生成回复，再通过模拟键鼠发送。

整个流程不依赖任何云端服务：没有账号体系，没有遥测，截图和对话内容只会发送到你自己填写的模型端点。

## 功能

- 通用 IM 支持：只依赖截图和视觉模型，不做应用专属逻辑，微信、企业微信、飞书、WhatsApp 等聊天窗口都按同一套流程处理。
- 自动回复：识别当前会话里对方的新消息，生成回复。可选“自动发送”，或“生成后由我确认再发送”（默认）。
- 未读会话切换：当前会话处理完后，自动点击会话列表里的未读红点，继续处理其他会话。
- 定时与指定联系人任务：按 cron 或一次性时间，向指定联系人发送文字或图片；会自动搜索联系人并校验打开的会话。
- 联系人画像：每个联系人在本地保存标签、已知信息、沟通偏好和往来摘要，回复时按字数预算注入提示词。
- 智能体：管理多套回复提示词，同一时间启用一个，决定回复的角色、语气和规则。
- 多模型分工：识别、回复、画像三个角色可分别配置模型，未单独配置时沿用上一级。
- 预留的接入点：本机控制 API、远程 WebSocket 任务源、可替换的输入后端。

## 界面

- 主面板：窄的悬浮面板。顶部是状态胶囊和三个图标（设置、运行日志、关闭），中间是提示、待确认回复和运行动态，底部是启动或暂停、速度档位、回复方式和选窗口按钮。
- 设置窗口：左侧是“对话 / 智能体 / 功能”三个分组页签，右侧是内容。
  - 对话：运行日志、模型用量。
  - 智能体：智能体、特定任务、联系人画像。
  - 功能：模型、引擎与输入、本机 API、远程任务源。

## 快速开始

环境要求：Windows 10 或 11，Node 20.19 以上或 22.12 以上。目前通过源码运行，还没有安装包。

```bash
npm install
npm run dev
```

其他命令：

```bash
npm run build        # 构建到 out/
npm run typecheck    # 主进程与渲染进程类型检查
npm test             # 单元测试与引擎集成测试
```

Electron 二进制默认从国内镜像下载，地址写在 `.npmrc` 里。网络环境不需要的话可以删掉那一行。

## 首次使用

1. 点主面板右上角的齿轮，进入 设置 → 功能 → 模型，填写识别模型的端点、密钥和模型名，点“保存并测试”。识别模型必须支持图片输入。
2. 回到主面板，点右下角的选窗口按钮，或按 Ctrl+Alt+S，移动鼠标高亮目标聊天窗口，点击确认。目标窗口必须可见，不能最小化或收在托盘里。
3. 点“启动”。

运行期间会真实地移动鼠标、点击和输入，请不要同时操作键盘鼠标。建议先用测试账号和测试聊天窗口试运行。

快捷键：

| 快捷键 | 作用 |
|---|---|
| Ctrl+Alt+S | 选择目标窗口（引擎运行中不可用） |
| Ctrl+Alt+P | 暂停或恢复 |
| Esc | 退出选窗口浮层 |

## 工作原理

1. 截取目标窗口所在显示器，按窗口边界裁剪。
2. 把画面缩成缩略图，统计亮度明显变化的像素占比；变化超过阈值才调用视觉模型。画面长时间没有变化时，每隔一段时间也会强制识别一次，防止漏掉小面积的新消息。
3. 视觉模型返回会话名、搜索框、输入框、消息列表和未读红点，坐标是相对截图的 0 到 1000 的归一化值。
4. 引擎对比前后两次的消息列表找出新增消息。启动时屏幕上已有的消息视为历史基线，不会回复。
5. 有新的对方消息时，由回复模型结合智能体提示词和联系人画像决定回复或跳过。
6. 发送时先在输入框内取随机点点击，剪贴板写入文本后粘贴，再按发送键，结束后恢复原剪贴板。
7. 当前会话处理完后，如果识别到未读红点，就点击红点切到下一个会话。点击前会用新截的一张图核对会话列表区域和识别时是否一致，微信有新消息时会话会跳到顶部，位置变了就重新识别后再点击，红点已消失则放弃这次切换。连续多次切过去没有新消息时，会暂停切换 60 秒。
8. 在确认模式下，草稿按会话排队。确认发送时会先检查当前打开的是不是草稿所属的会话，不是就通过搜索切回去再发送。

## 配置说明

模型：

- 端点需要兼容 OpenAI 接口，支持 `chat`（chat/completions）和 `responses` 两种协议。
- 回复模型和画像模型没有单独填写端点或密钥时，沿用上一级（回复沿用识别，画像沿用回复）。
- “额外请求参数”是一个 JSON 对象，会合并进请求体。例如阿里云百炼的 Qwen3 系列默认可能开启思考，识图一次会慢到一分钟以上，可以填 `{"enable_thinking": false}` 关闭。
- 端点、密钥和模型名两端的空白会被自动去掉。

引擎与输入：

| 设置 | 说明 |
|---|---|
| 回复方式 | 自动发送，或生成后由我确认 |
| 速度档位 | 主面板上的极速、标准、省电，对应不同的轮询间隔 |
| 界面变化灵敏度 | 变化像素占比的阈值，越小越灵敏，默认 0.003 |
| 兜底识别间隔 | 画面无变化时的强制识别间隔，默认 45 秒，0 为关闭 |
| 切换未读的方式 | 点击红点，或快捷键 Ctrl+G（仅微信） |
| 发送键 | Enter、Ctrl+Enter，或兼容序列 |
| 随机变化 | 鼠标轨迹和操作间隔是否加入随机 |

## 本机 API

在 设置 → 功能 → 本机 API 里启用，只监听 `127.0.0.1`。请求必须带 `Authorization: Bearer <令牌>`，带 `Origin` 头的浏览器请求和异常的 Host 会被拒绝。

| 接口 | 作用 |
|---|---|
| `GET /status` | 引擎状态 |
| `POST /pause` | 暂停 |
| `POST /resume` | 恢复 |
| `POST /stop` | 停止 |
| `POST /tasks` | 入队一个发送任务 |

任务请求体：

```json
{
  "id": "可选，不填自动生成",
  "target": { "name": "张三", "chatType": "single" },
  "actions": [
    { "type": "text", "text": "你好" },
    { "type": "image", "path": "D:\\pics\\a.png" }
  ]
}
```

`chatType` 可选 `single` 或 `group`。任务只有在引擎运行并选定了目标窗口后才会执行。

## 目录结构

| 路径 | 作用 |
|---|---|
| `src/shared` | 跨进程类型、设置 schema、IPC 通道白名单 |
| `src/main/capture` | 窗口探测、截图、坐标换算、画面变化检测 |
| `src/main/executor` | 输入后端（robotjs 子进程）、拟人化轨迹、剪贴板粘贴与发送键 |
| `src/main/vision` | 视觉识别接口与基于模型的实现 |
| `src/main/brain` | 回复决策 |
| `src/main/profile` | 联系人画像存储与抽取 |
| `src/main/scheduler` | 任务源接口、本地定时调度、远程 WebSocket 任务源 |
| `src/main/engine` | 状态机、新消息追踪、任务执行 |
| `src/main/windows` | 主面板、设置窗口、选窗口浮层 |
| `src/main/api` | 本机控制 API |
| `src/preload`、`src/renderer` | 预加载白名单桥与界面 |

## 扩展点

- 输入后端：实现 `src/main/executor/inputBackend.ts` 里的 `InputBackend`，可接入外接硬件等其他输入方式。
- 任务源：实现 `src/main/scheduler/taskSource.ts` 里的 `TaskSource`，通过 `TaskSink.submit` 下发任务，用 `report` 接收结果。`src/main/scheduler/remote/wsTaskSource.ts` 给出了一个 WebSocket 实现和协议，默认关闭。
- 视觉识别：实现 `src/main/vision/vlmVision.ts` 里的 `VisionProvider`，可以换成自己的检测模型。

## 数据与隐私

设置、联系人画像、定时任务和日志都保存在 Electron 的 userData 目录（Windows 上是 `%APPDATA%\im-agent`）：

| 路径 | 内容 |
|---|---|
| `settings.json` | 设置，模型密钥与令牌经系统凭据加密 |
| `profiles/` | 联系人画像，每人一个 JSON 文件 |
| `tasks.json` | 本地定时任务 |
| `logs/app.log` | 运行日志，超过 2 MB 会轮转 |

应用不会上传日志和截图。截图和对话内容只发送到你在“模型”页配置的端点。联系人画像功能启用后，对话内容会发送到画像模型，不需要时可以在设置里关闭。

## 已知限制

- 仅支持 Windows。
- 识别准确度取决于所用的视觉模型。点击坐标来自模型返回的框，窗口布局特殊时可能点偏。
- 目标窗口被其他窗口遮挡时，截到的是遮挡物，所以运行期间请保持目标窗口在最前且可见。
- 切换未读时会点击所有带红点的会话，包括静音的群。
- 外接硬件输入目前只有接口，没有实现。
- 自动化操作聊天软件可能违反该软件的服务条款，请自行评估并承担风险。
