# 硬件 HID 模组接入

im-agent 可以把键鼠操作交给外接的 USB HID 模组：本机通过模组的虚拟串口发送文本指令，模组再向本机输出真实的 USB 键盘和鼠标信号，目标软件看到的是一个普通的 USB 键鼠，而不是 `SendInput` 之类的软件注入。

目前适配的是创亿物联的 cyStudio 模组（USB 标识 `1A86:FFFF`，插入后出现一个虚拟串口和一组 HID 键鼠）。模组本身是可编程的，串口协议由下载到模组里的 cyStudio 工程决定。本文定义 im-agent 使用的协议，并说明模组侧工程怎么搭。

> 模组侧的连线是按 cyStudio v1.08 手册写的，没有在真机上验证过。组件名称、参数以实际软件为准，第一次对接时请先按“联调步骤”逐条验证。

## 使用

软件模拟（robotjs）一直保留，硬件 HID 只是多出来的一种输入方式。设置 → 功能 → 引擎与输入 → 键鼠输入里的“输入方式”有三档：

| 输入方式 | 行为 |
|---|---|
| 自动（默认） | 先找模组的串口并发一条 `P`，模组回 `OK` 就走硬件，否则走软件模拟。探测成功缓存 30 秒，失败缓存 15 秒，之后重新探测，模组中途插上会被识别。硬件操作失败时，本次回退到软件，并让同一类操作（“鼠标”或“键盘”）暂停尝试硬件 60 秒，另一类不受影响，所以模组里只搭了按键时，按键走硬件、鼠标走软件；硬件表达不了的输入（如冷门按键）只让那一次走软件。 |
| 软件模拟 | 只用 robotjs，不碰串口。 |
| 硬件 HID 模组（手动指定） | 识别不了模组、或者想强制使用硬件时选它。不探测也不回退，失败就直接报错。 |

实际使用的是哪一种，会在运行日志里写一条“键鼠输入切换为……”，并带上原因。

准备步骤：

1. 按下文在 cyStudio 里搭好工程并下载到模组，然后在 cyStudio 里点连接按钮断开连接（连接时 cyStudio 会占用虚拟串口，自动模式会因为打不开串口而回退到软件）。
2. 串口号留空会按 `1A86:FFFF` 自动查找，也可以手动填 `COM3`。
3. 模组的 USB 线必须接在运行 im-agent 的这台电脑上，HID 动作作用在这台电脑上。

## 串口协议

- 串口参数 115200 8N1（USB CDC 实际不受波特率限制）。
- 每条指令是一行 ASCII 文本，以 `
` 结尾。**指令字母后面紧跟参数，不加空格**（`Kctrl+v`，不是 `K ctrl+v`），因为模组侧用“起始符”区分指令。
- 模组执行完一条指令后回一行 `OK
`。im-agent 收到 `OK` 才发下一条，超过 3 秒没有 `OK` 视为模组没有响应并报错。设置里可以关闭“回执”，关闭后每条指令之间只留约 8 ms 间隔，模组处理不过来时会丢指令，仅建议联调时使用。

| 指令 | 含义 | 模组侧状态 |
|---|---|---|
| `P` | 连通性检查，回 `OK`；自动模式靠它识别模组 | 已搭建，真机验证通过 |
| `K<combo>` | 键盘按键单击，单键或组合键，如 `Kenter`、`Kctrl+v`，键名见 HID 组件手册的键码表 | 已搭建，真机验证通过（`Kctrl+a` 在记事本全选） |
| `M<XXXX><YYYY>` | 鼠标绝对定位，X、Y 各是 4 位大写十六进制，取值 0000~FFFF，是主屏宽高归一化后的值，如 `M7FFF7FFF` 是屏幕中心 | 已搭建，真机验证通过 |
| `DL` / `UL` | 鼠标左键按下 / 松开 | 已搭建，真机验证通过 |
| 右键、中键、滚轮、`T` 直接输入字符串 | | 未搭建，im-agent 遇到时在自动模式下走软件模拟 |

说明：

- 模组里没搭的指令，im-agent 在“自动”模式下按操作类型回退到软件模拟；在“硬件 HID 模组（手动指定）”下，右键、滚轮、直接输入字符串会直接报错，另外，模组没回应的指令也会报错。im-agent 目前实际只用到左键点击、移动和几个固定组合键，所以已搭建的这些就够用。
- 绝对坐标只覆盖主屏。目标窗口不在主屏上时，点位会被收进主屏边缘，请把聊天窗口放在主屏。
- 点击由按下、松开两条指令加中间的随机停顿组成，所以按下时长可以随机变化。
- 中文等非字母数字内容不走 `T`，im-agent 依然通过剪贴板粘贴（模组发送 `Kctrl+v`）。

## 模组侧 cyStudio 工程

产品类别选“调试”，产品型号选 `USB<->IO`（模组上报的设备名就是它）。工程结构如下，每条指令一个“通用字符协议解析”，用起始符区分：

```
                  ┌─ 解析 K（起始符 K / 帧数据 / 结束符 0A）─ 帧数据 ───────► HID[键盘按键单击] ──┐
                  ├─ 解析 P（起始符 P / 结束符 0A）──────── 结束符 ───────────────────────────────┤
虚拟串口 ─────────┼─ 解析 M（起始符 M / UINT16 十六进制 4 字节 ×2 / 结束符 0A）─ X、Y ─► HID[鼠标定位，屏宽屏高 65535] ─┤
                  ├─ 解析 DL（起始符 DL / 结束符 0A）─ 结束符 ───────────────► HID[鼠标左键按下] ─┤
                  └─ 解析 UL（起始符 UL / 结束符 0A）─ 结束符 ───────────────► HID[鼠标左键松开] ─┤
                                                                                                     ▼
虚拟串口 ◄───────────────────────────── 常量(16#数组 4F 4B 0A) ◄───────────────────────────────────┘
```

搭建要点：

1. **用起始符区分指令**：每种指令各用一个 `通用字符协议解析`，第一行“起始符_STRING”填指令字母（`K`、`P`、`M`、`DL`、`UL`，字节数填字符个数），最后一行“结束符_16#数组”填 `0A`（换行）。起始符对不上的组件只会给出警告，不会输出，所以不需要额外的分发组件。
2. **帧数据行的字节数要填**（填 1 即可），否则检查会报“字符长度为空”。
3. **按键**：解析 K 的“帧数据”行输出是字符串（如 `ctrl+v`），直接接 `HID`（操作选“键盘按键单击”）。HID 的输入接受 STRING、10#数组、16#数组。
4. **鼠标移动**：解析 M 里 X、Y 各用一行 `UINT16`，字节数 4，参数选“16进制”，两行的输出分别接 `HID`（操作选“鼠标定位”）的 X、Y 输入；该 HID 的屏宽、屏高都填 `65535`，这样 0000~FFFF 正好对应整个主屏。
5. **左键**：解析 DL、UL 的“结束符”行输出分别触发 `HID`（操作选“鼠标左键按下”、“鼠标左键松开”），这两个 HID 对输入数据类型没有要求，有输入就动作。
6. **回执**：`常量` 组件数据类型选 `16#数组`，内容 `4F 4B 0A`，任何输入都会触发它输出。所有 HID 的输出（完成）和解析 P 的结束符输出都接到它，它的输出再接回 `虚拟串口` 的输入。
7. **接线**：组件的输出点只有在组件未被选中时才能拖出连线；选中状态下拖动输出点只会让它沿边缘移动。
8. **拖入组件**：从组件区往画布拖时，个别落点会无效（组件没出现），换个位置再拖即可。
9. 不要再放会往虚拟串口发数据的其他组件，避免回执被打乱。

## 联调步骤

先不跑 im-agent，用任意串口助手，或项目自带的 `node scripts/hid-probe.mjs`（不带参数进入交互模式，或直接跟指令，如 `node scripts/hid-probe.mjs "P" "Kctrl+a" "M7FFF7FFF"`），在 cyStudio 已断开连接、串口空闲时按顺序验证：

1. 发送 `P`，应收到 `OK`。
2. 在记事本里输入一段文字，发送 `Kctrl+a`，应看到全选，并收到 `OK`。
3. 发送 `M7FFF7FFF`，鼠标应移到主屏中心；再依次发送 `DL`、`UL`，应有一次左键点击；每条都应收到 `OK`。
4. 以上都正常，再在 im-agent 里把输入方式设为“硬件 HID 模组”（或自动），选一个测试聊天窗口试运行。

## 已知限制

- 硬件后端只能向主屏输出绝对坐标。
- 非字母数字文本必须靠剪贴板粘贴，所以仍会读写系统剪贴板。
- 光标起点读取的是系统光标位置，这属于只读查询，不是输入注入。
- 模组程序断电后是否保留，没有在手册里找到说明，也还没有实测，请拔插一次 USB 后发 `P` 确认。
- 单条指令往返约 6~11 ms；拟人化移动一次约 12~40 步，整段耗时约 1 秒，比软件模拟慢一些。
- 在 Windows 上 serialport 的回调只在事件循环被唤醒时处理，等待回执期间代码里用了 5 ms 的心跳定时器，不要去掉，否则回复会被拖到超时。
- cyStudio 偶尔会在重新连接模组时提示“链路超时”（重试一次通常就连上了）；下载程序必须用 cyStudio（下载协议没有公开），下载只需一次，之后不再需要它。
